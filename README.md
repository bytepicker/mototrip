# MotoTrip — планировщик мотопутешествий

SPA для планирования поездок на мотоцикле. React + TypeScript + Vite + Leaflet.

## Версия 0.2.0

- Маршрут строится через **все точки списка** в указанном порядке: старт, достопримечательности, заправки, кемпинги, магазины, кафе, сервисы, промежуточные точки и финиш.
- После успешного построения маршрута приложение автоматически ищет объекты OpenStreetMap вдоль линии маршрута через Overpass API.
- Найденные POI отображаются отдельными маркерами. Категории можно включать и выключать.
- В карточке найденного объекта можно добавить его в маршрут. Добавленная точка становится полноценной маршрутной остановкой.
- После изменения координат или порядка точек линия помечается как устаревшая; маршрут можно перестроить.
- Экспорт GPX: все плановые остановки экспортируются как GPX waypoints, построенная дорожная геометрия — как track.
- Импорт GPX: читаются waypoints/route points; существующая геометрия track сохраняется на карте. Если в файле нет waypoints/route points, используются начало и конец track.
- Сохранены функции прототипа: несколько маршрутов, локальное сохранение, ссылки, JSON import/export, поиск места.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Сборка: `npm run build`.

## GitHub Pages

Workflow находится в `.github/workflows/deploy.yml`. Загрузи содержимое проекта в `main`, выбери **Settings → Pages → Build and deployment → GitHub Actions**. При push workflow соберёт `dist` и опубликует сайт.

## Источники данных и ограничения

- Карта и POI: OpenStreetMap, лицензия ODbL. Сохраняй атрибуцию.
- POI: публичный Overpass API. Запрос выполняется после построения маршрута; есть клиентская пауза между запросами. Публичные экземпляры — общие ресурсы, могут быть перегружены или временно недоступны. Не запускай массовый поиск и не используй публичный Overpass как гарантированный backend для большого публичного сервиса.
- Геокодирование: публичный Nominatim, запрос только по кнопке.
- Маршрутизация: публичный OSRM demo endpoint, автомобильный профиль, best-effort без SLA. В запрос передаются все точки списка, поэтому маршрут проходит через добавленные места. Для регулярной/массовой нагрузки понадобится отдельный routing backend.
- Данные поездок хранятся в LocalStorage браузера. Ссылки содержат сериализованный маршрут в URL hash.
