# MotoTrip

Планировщик маршрутов для мотопутешествий. Помогает собрать поездку на карте, добавить остановки, построить маршрут по дорогам и поделиться им ссылкой.

## Возможности

- Создание и редактирование нескольких маршрутов.
- Добавление старта, финиша и промежуточных точек кликом по карте или поиском места.
- Категории остановок: достопримечательности, заправки, кемпинги, магазины, кафе и мотосервисы.
- Построение маршрута через все точки, ручная перестановка и автоматический подбор порядка остановок.
- Поиск объектов вдоль маршрута через NextGIS Overpass и кэширование результатов в браузере.
- Оценка времени поездки: отдельно время за рулём, время остановок и общая продолжительность.
- Настраиваемая длительность каждой остановки с предварительными значениями по категориям.
- Импорт и экспорт маршрутов в JSON и GPX, включая дорожный трек.
- Передача маршрута по ссылке.

## Оценка времени

Время за рулём рассчитывается сервисом OSRM. Для промежуточных остановок MotoTrip подставляет условную длительность по категории: обычная точка — 15 минут, заправка — 20 минут, магазин — 20 минут, кафе — 45 минут, достопримечательность — 60 минут, мотосервис — 60 минут, кемпинг — 8 часов (условная ночёвка). Значение можно изменить для каждой точки, в том числе установить 0 минут.

Это ориентир для планирования, а не прогноз прибытия: фактическое время зависит от трафика, погоды, состояния дорог, скорости движения и реальной длительности отдыха. Используется автомобильный профиль OSRM, не специализированный мотоциклетный профиль.

## Как пользоваться

1. Создайте маршрут и добавьте старт, финиш и промежуточные точки.
2. При необходимости измените порядок точек вручную или воспользуйтесь автоматической оптимизацией.
3. Постройте маршрут через все точки.
4. Выберите остановку в списке, чтобы изменить её название, категорию, заметку или предполагаемое время.
5. При необходимости найдите POI вдоль маршрута и добавьте подходящие места.
6. Нажмите **«Поделиться»**, чтобы скопировать ссылку на маршрут.

Для поиска POI нужен персональный API-ключ NextGIS Overpass. Его можно создать в личном кабинете NextGIS и сохранить в настройках панели «Объекты на карте». Ключ хранится в LocalStorage браузера и не включается в репозиторий, но используется непосредственно из браузера и поэтому виден в сетевых запросах.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Публикация на GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment** и выберите **GitHub Actions**. Workflow `.github/workflows/deploy.yml` собирает приложение и публикует сайт при push в ветку `main`.

## Данные и ограничения

- Карта и POI: [OpenStreetMap](https://www.openstreetmap.org/), данные распространяются по лицензии ODbL; сохраняйте атрибуцию.
- Поиск POI: [NextGIS Overpass](https://docs.nextgis.ru/docs_ngcom/source/services.html). Доступность и ограничения сервиса определяются его условиями.
- Поиск мест: публичный Nominatim.
- Маршрутизация: публичный OSRM demo endpoint с автомобильным профилем. Публичные сервисы предоставляются без гарантии доступности и могут ограничивать частоту запросов.
- Маршруты, настройки и кэш POI хранятся в LocalStorage браузера и автоматически не синхронизируются между устройствами.
- Ссылки на маршруты содержат сериализованные данные поездки в URL. Не включайте в маршрут конфиденциальную информацию.

## Технологии

React, TypeScript, Vite, Leaflet, OpenStreetMap, OSRM, NextGIS Overpass.
