# MotoTrip

Планировщик маршрутов для мотопутешествий. Позволяет собрать поездку на карте, добавить остановки, построить маршрут по дорогам и поделиться им ссылкой.

## Возможности

- Создание нескольких маршрутов и добавление точек кликом по карте или поиском места.
- Типы точек: старт, финиш, промежуточная остановка, достопримечательность, заправка, кемпинг, магазин, кафе и мотосервис.
- Построение маршрута через все добавленные точки с отображением расстояния и примерного времени в пути.
- Ручное изменение порядка остановок и автоматический подбор их последовательности с фиксированными стартом и финишем.
- Поиск объектов вдоль маршрута: достопримечательности, заправки, кемпинги, магазины, кафе и мотосервисы. Найденные места можно добавить в маршрут.
- Кэширование результатов поиска объектов в браузере.
- Импорт и экспорт маршрутов в JSON и GPX.
- Создание ссылки для передачи маршрута другому человеку.

## Как пользоваться

1. Откройте приложение и создайте маршрут.
2. Добавьте старт, финиш и промежуточные точки — кликом по карте или через поиск места.
3. При необходимости измените порядок остановок вручную или нажмите **«Автоматически упорядочить остановки»**.
4. Нажмите **«Построить маршрут через все точки»**.
5. После построения маршрута можно найти объекты вдоль него, включить нужные категории и добавить подходящие места в поездку.
6. Кнопка **«Поделиться»** копирует ссылку на текущий маршрут. Получатель откроет её в браузере, а маршрут сохранится в его локальном хранилище.

Для поиска объектов укажите собственный API-ключ NextGIS Overpass в настройках раздела **«Объекты на карте»**. Ключ сохраняется в браузере и не требуется для построения обычного маршрута.

## Запуск локально

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Публикация на GitHub Pages

В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** в разделе *Build and deployment*. Workflow `.github/workflows/deploy.yml` собирает приложение и публикует его при push в ветку `main`.

## Используемые сервисы и данные

- **OpenStreetMap** — картографические данные и POI. Данные OSM распространяются по лицензии ODbL; сохраняйте атрибуцию OpenStreetMap.
- **NextGIS Overpass** — поиск объектов вдоль маршрута. Для запросов нужен API-ключ NextGIS. Доступность и ограничения сервиса определяются его условиями.
- **Nominatim** — поиск мест по названию.
- **OSRM** — построение маршрутов и расчёт дорожных расстояний.

Маршрутизация сейчас использует профиль `driving`, а не специализированный мотоциклетный профиль. Поэтому приложение не учитывает мотоциклетные предпочтения и не гарантирует выбор подходящих для мотоцикла дорог. Внешние публичные сервисы предоставляются без гарантий доступности и могут ограничивать частоту запросов.

## Хранение данных

Маршруты, настройки и кэш POI хранятся в LocalStorage браузера. Они не синхронизируются между устройствами автоматически. Ссылки на маршруты содержат данные маршрута в URL, поэтому передавайте их как обычные ссылки и учитывайте, что получатель сможет просмотреть содержимое маршрута.
