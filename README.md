# MotoTrip — планировщик мотопутешествий

Небольшое SPA-приложение для планирования поездок на мотоцикле. React + TypeScript + Vite + Leaflet.

## Возможности прототипа

- Создание нескольких маршрутов и редактирование названия/описания.
- Интерактивная карта OpenStreetMap: клик добавляет точку с координатами.
- Категории точек: промежуточная точка, достопримечательность, АЗС, кемпинг, магазин, еда/кафе, мотосервис.
- Редактирование названия, заметки и категории точки; перемещение точек вверх/вниз и удаление.
- Поиск места по названию через Nominatim (ручной запрос, без автодополнения).
- Построение дорожного маршрута через OSRM (автомобильный профиль) с расстоянием и временем.
- Локальное сохранение в LocalStorage.
- Поделиться ссылкой (маршрут кодируется в URL hash), экспорт/импорт JSON.
- Адаптивный интерфейс для мобильных экранов.

## Запуск локально

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Бесплатная публикация на GitHub Pages

1. Создай пустой репозиторий на GitHub, например `mototrip`.
2. Загрузи содержимое этого каталога в ветку `main` (включая `.github/workflows/deploy.yml`).
3. Открой **Settings → Pages** и выбери **GitHub Actions** в разделе Build and deployment.
4. Дождись завершения workflow **Deploy MotoTrip to GitHub Pages**.
5. Сайт будет доступен по адресу `https://<твой-логин>.github.io/<имя-репозитория>/`.

Workflow автоматически задаёт `VITE_BASE` из имени репозитория. Если используешь специальный user-site репозиторий `<логин>.github.io`, поменяй `VITE_BASE` в `.github/workflows/deploy.yml` на `/`.

## Внешние сервисы и ограничения

- Карта: стандартные тайлы OpenStreetMap. Соблюдай [политику использования тайлов](https://operations.osmfoundation.org/policies/tiles/), не добавляй массовую загрузку/офлайн-кэширование и сохрани атрибуцию.
- Поиск: публичный Nominatim. Запрос выполняется только по кнопке; не используй автодополнение и не превышай ограничения публичного сервиса.
- Маршрутизация: публичный OSRM demo endpoint. Это best-effort сервис без SLA, для небольшого прототипа; не делай частые запросы. Для реального публичного продукта стоит подключить отдельного провайдера или собственный сервер маршрутизации.
- Все пользовательские данные остаются в LocalStorage браузера. Ссылка содержит данные маршрута в открытом виде (не отправляй через неё приватную информацию). Ссылка может стать длинной при большом количестве точек.
